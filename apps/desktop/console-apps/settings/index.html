Activity Island

灵动岛是屏幕顶部的一条常驻信息条。它平时不占地方，有事情发生时才冒出来提醒你—— 系统通知、设备状态、传输进度、任务结果。点一下展开看详情，再点一下收起，不需要打开大型应用。

小岛一条窄横条，只显示最关键的预览。提醒时短暂出现，平时不占位。
中岛点小岛展开。看完整内容，做一两个简短操作。
大岛需要更多空间时继续展开，留给复杂任务（如传输进度）。
工作台右键小岛打开的全屏面板，放搜索、历史这类密集任务。

基本操作

鼠标就够
悬停鼠标移到待机胶囊上，它会展开成信息条。
单击展开当前内容；再点一次进入更大一档。
右键打开工作台。托盘图标右键可打开控制台或退出。
拖拽在「插件」页把芯片拖到想要的位置，决定岛上从左到右的顺序。

通知

内置，无需插件

软件会接管 Windows 通知中心里出现的通知，把它们显示在岛上：小岛看过一眼，中岛看全文。 通知历史可从灵动岛右侧菜单打开，集中管理。

读取哪些所有进入通知中心的应用通知。首次使用需要在系统设置里允许访问通知。
怎么不打扰「通知」页里可暂停提醒、按应用过滤、设免打扰时段。这些只影响提醒，历史始终记录。
原生横幅Windows 不允许程序拦截横幅。想让某个应用只在岛上提醒，就把它的系统通知样式改为「仅显示在通知中心」。

本地接口

给脚本用

软件在本机开了一个 HTTP 端口，任何脚本、CI、其他程序都可以往里推一条通知，直接上岛。 默认只绑定 127.0.0.1，需要令牌才能调用。

curl -X POST http://127.0.0.1:5720/api/v1/notifications \
  -H "Authorization: Bearer <令牌>" \
  -H "Content-Type: application/json" \
  -d '{"title":"构建完成","content":"用时 42 秒","level":"warn"}'

令牌、端口与实际端点见「通知」页。字段支持 title / content / level / ttl / dedupeKey。

测试工具

发一条通知看看效果

端口发送走真实 HTTP + 令牌 + 管道。填局域网 IP 可验证「局域网可访问」是否真的生效。
Windows 通知发起真实系统通知，验证「通知中心 → 监听 → 上岛」。
直接注入跳过网络与系统通知，只验证展示与提醒样式，最不容易受环境影响。

常见问题

—
岛上没有通知先确认「通知」页里 Windows 通知显示「监听中」；没授权就去系统设置允许访问通知。
接口调不通看「通知」页的端点和令牌；确认本地接口是「运行中」。端口被占用时可在同一页换端口。
全屏时看不到岛前台应用全屏时岛会自动隐藏，避免遮挡。退出全屏即恢复。
通知只有应用名Windows 通知中心本身可能只提供应用名和标题，读不到应用内部更细的文字。
